VCS Game Maker, VCS portable (Linux, 64-bit Intel/AMD)

Made for the Atari VCS (AtariOS, Debian 10) and works on other 64-bit Linux systems too.
Nothing is installed: unpack this archive anywhere and run VCS-Game-Maker.sh (from a terminal: ./VCS-Game-Maker.sh).

If the app does not start, run it from a terminal: a line starting with "VCS Game Maker needs these system libraries"
lists what the system lacks.
