VCS Game Maker is a visual environment for building Atari 2600 games. Build your game's logic with Blockly blocks, and behind the scenes VCSGM generates batari Basic source code (along with a bit of assembly), compiles it into an Atari 2600 ROM, and runs it in the built-in emulator preview, using either 6502.ts or Gopher2600.

This is very much a work-in-progress.

Features

Blocks in,
ROM out

Put the logic of your game together from Blockly blocks. VCS Game Maker then writes batari Basic (and a little assembly), compiles it into an Atari 2600 ROM.

Standard & DPC+ kernels

Use the Standard DPC+ kernel (wip) for more sprites, a taller playfield, per-row colors and a coprocessor.

sound & music

Design sound effects with envelopes and arpeggios, draw waveforms for the DPC+ sound chip, and compose songs in a full-featured music editor.

Runs ON WHATEVER

Use it in the browser or install the desktop app. Supports Windows, macOS, and Linux.

GET code,
BUILD ON IT

The Generated tab shows the batari Basic your blocks turn into, so you can read it, learn from it and build on it in other development software.

Examples & sound banks

Download example projects, music, instrument and sound effect banks directly inside the app.

Sprites and animation

Draw your graphics and animations right in the app, or import directionly from Aseprite.

The sprite editor has the usual drawing tools, selections and mirroring. An animation is a row of frames, each with a set duration, and every row of pixels in a sprite can have a different color. Sprites can be 8 or 16 pixels wide, and an Aseprite sprite sheet imports with its frames and their durations.

BACKGROUNDS & PlayfieldS

Draw full-screen playfield backgrounds in the editor, where each pixel is on or off, and keep as many backgrounds as you need. It has the same drawing tools as the sprite editor, plus a display of pixel coordinates, and with per-row colors turned on every row of the playfield can be given a different color. A preview button shows a background on the emulator's screen, and you can import and export images. With the DPC+ kernel a background can be taller than the screen.

Sound and music

Make sound effects and songs without writing any code. The sound effect editor shapes TIA sounds with envelopes and arpeggios, and on DPC+ it lets you draw a waveform that the coprocessor plays. The music editor builds songs from patterns and instruments, and the instruments are simply sounds from the Sound tab. You can also download sound banks and example projects from inside the app.

Text, scores and title screens

The text minikernel shows messages on the screen, by name or by ID, as scrolling text, or as text that clears itself after a number of frames. You can choose a score font, set the score and its colors, and design title screens in an editor made for them.

Pick the Standard kernel for a plain 2600 game, or the DPC+ kernel for more sprites, a taller playfield and a coprocessor.

Ways to view the app

Pick the look that suits you in the Options tab. Dark mode, the subdued palette, high contrast and expert mode each work alone or together, and either toolbar can be hidden. Here is the same project in every combination.

Recent updates

Version 0.52.28 (release page)

The Playfield offset block and the box test for collisions run on the DPC+ coprocessor, for any area and in all directions, with fewer variables and less time each frame. The offset block has a new "alternate rows right and left" option.

Collided blocks that name Player 1 are now exact in a DPC+ project that uses Players 2 to 9, so a virtual sprite no longer triggers Player 1's collisions.

A new "Clear text after N frames" block clears any text block's message after the time you set. "Set animation to" can start at any frame, and "When animation has finished" runs once. Reordering or deleting animations keeps the blocks that name them pointing at the right one.

Each sound remembers whether it is set to TIA or to the coprocessor. DPC+ waveforms in the sound banks now preview as themselves. Saved files record the app version, and example projects and sound banks from a newer version are not listed.

Fixes: the last playfield line with the score on in DPC+, the picture height with "Show text row" blocks, and disabled blocks no longer change the generated code. Many variables were saved by packing and sharing bytes.
