Build Atari 2600 games with blocks.

Open in your browser Official itch.io Documentation / Wiki

VCS Game Maker is a visual development environment for building Atari 2600 games. Design your game's logic with Blockly blocks, and behind the scenes VCSGM generates batari Basic source code (along with a bit of assembly), compiles it into an Atari 2600 ROM, and runs it in the built-in emulator preview, using either 6502.ts or Gopher2600.

This is very much a work-in-progress.

Features

Blocks in,
ROM out

Put the logic of your game together from Blockly blocks. VCS Game Maker then writes batari Basic (and a little assembly), compiles it into an Atari 2600 ROM.

Standard & DPC+ kernels

Use the Standard kernel, or upgrade to the DPC+ kernel (wip) for more sprites, a taller playfield, per-row colors and a coprocessor.

sound & music

Design sound effects with envelopes, arpeggios and slides. Draw waveforms for the DPC+ sound chip, and compose songs in a full-featured music editor.

Runs ON... WHATEVER

Use it in the browser or install the desktop app. Supports Windows, macOS, and Linux.

VIEW code,
BUILD ON IT

The Generated tab shows the batari Basic your blocks turn into, so you can read it, learn from it and build on it in other game development software.

Examples & sound banks

Download example projects, music, instrument and sound effect banks directly inside the app.

Sprites & animation

Draw sprites with extensive built-in drawing tools, or import files from Aseprite, automatically creating all of your animations with perfect frame timing.

BACKGROUNDS & PlayfieldS

Draw full-screen playfield backgrounds in the editor. It has the same drawing tools as the sprite editor, with per-row playfield and background colors. Preview backgrounds directly in the emulator so you can get things pixel-perfect easily.

Sound & music

Make sound effects and songs without writing any code. The sound effect editor shapes TIA sounds with envelopes and arpeggios, and on DPC+ lets you directly waveforms.

The music editor lets you builds songs from patterns, with downloaded or custom instruments designed on the Sound tab.

Text & scores

The Text minikernel shows messages on screen, by text name or ID. VCS Game Maker additions include up to 2 lines of text on-screen with independent line colors, scrolling text, and multi-line dialog text up to 255 characters long.

The score is a six-digit display (or five, if you prefer) that your blocks can set, add to and read. Pick a built-in font, a compact Squish font that frees room for the text rows, or draw custom digits, and give the score row a background color that can differ from the playfield's.

Title screens

Design and animate high-quality, full-color title screens in the editor, and display them with built-in Title Screen kernel support. Build each screen from stacked image strips and add as many pages as you like. Strips can be a single color for the sharpest result, or give each row a different color. The editor has the same drawing tools as the other graphics editors, and you can import and export images.

USE IT YOUR WAY

Pick the look that suits you in the Options tab. Dark Mode, Subdued Palette, High Contrast and Expert Mode allow you to customize the VCS Game Maker UI to your preferences.

Latest updates

Version 0.52.40 (release page)

The Windows installer installs into a "VCS Game Maker" Start Menu folder, and replaces an older version when you install a newer one.

The desktop version now tells you when a newer release is out, with a popup that shows the release notes and a link that downloads the file for your system. You can skip a version, or turn it off with "Notify me of new versions" in the options.

Songs take about half the space, and sound effects/instruments the same. Rests and hits are stored in a single byte, what the notes of an instrument share is stored once, and patterns with the same notes are stored once. Long arpeggio notes no longer skip a beat, and a long note with an envelope keeps its envelope for the whole note. A song and the Text minikernel no longer compete for the same bank of a ROM.

On a Title Screen, each Player sprite has a Start X, Start Y and Width, and the card no longer breaks the picture in some ROM layouts. Flipping a graphic upside down in the graphic editor now flips its row colors too.

The 6502.ts emulator shows the same picture as gopher2600, with the same shape of pixel.

Moving, deleting or copying a card (data table, title screen, playfield, sound, song, text message or sprite animation) numbers the cards again, and every block, data table cell and song instrument that names a card follows it.

A new "Undo steps" option sets how many steps back Undo goes on every tab (1 to 999, default 99). Undo and Redo now cover every drawing tool, Clear, pastes, the row color bars and the colors of title screen graphics, and save the picture at once.

New "VCS portable" download for Linux: an archive that runs from the folder it is unpacked into with no installation, made for AtariOS on the 2021 Atari VCS 800.

A value a project sets after "End title screen" (the stage a menu picked, say) now survives the start of gameplay.

The Playfield offset block and the box test for collisions run on the DPC+ coprocessor, for any area and in all directions, with fewer variables and less time each frame. The offset block has a new "alternate rows right and left" option.

Collided blocks that name Player 1 are now exact in a DPC+ project that uses Players 2 to 9, so a virtual sprite no longer triggers Player 1's collisions.

A new "Clear text after N frames" block clears any text block's message after the time you set. "Set animation to" can start at any frame, and "When animation has finished" runs once. Reordering or deleting animations keeps the blocks that name them pointing at the right one.

Each sound remembers whether it is set to TIA or to the coprocessor. DPC+ waveforms in the sound banks now preview as themselves. Saved files record the app version, and example projects and sound banks from a newer version are not listed.

Fixes: the last playfield line with the score on in DPC+, the picture height with "Show text row" blocks, and disabled blocks no longer change the generated code. Many variables were saved by packing and sharing bytes.
